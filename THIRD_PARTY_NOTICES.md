# Third-Party Notices

## Historical SSQ dataset mirror

The EdgeOne Makers data synchronization workflow may use historical records from:

- Repository: https://github.com/wangdaodao/DoubleColorBall
- Data path: data/YYYY.json and data/index.json
- Upstream license: MIT
- Upstream README describes 2013–present records as sourced from China Welfare Lottery public announcements and 2003–2012 records as sourced from the public Zhcw historical archive.
- SSQ Lab validates every imported record and overlays recent records from the Sichuan Welfare Lottery official website when available.

The upstream dataset is a third-party mirror, not the official lottery operator. Each bundled draw retains its source field. The current source label is shown by the application.
